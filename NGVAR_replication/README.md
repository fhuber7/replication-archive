# NG-VAR replication

Replication package for the Bayesian Vector Autoregressive (VAR) model with
a hierarchical Normal-Gamma (NG) shrinkage prior on the autoregressive
coefficients and stochastic volatility (SV) on the residuals.

Reference: Huber, F. and Feldkircher, M. (2019), "Adaptive shrinkage in
Bayesian vector autoregressive models", *Journal of Business and Economic
Statistics*, 37(1), 27-39.

## Model

For a VAR(p) of dimension M,

```
y_t = A_1 y_{t-1} + ... + A_p y_{t-p} + c + e_t,    e_t ~ N(0, Sigma_t).
```

The sampler uses the equation-by-equation triangular factorisation
`Sigma_t = U^{-1} D_t (U^{-1})'`, with U unit lower triangular and
`D_t = diag(exp(h_{1t}), ..., exp(h_{Mt}))`. Each `h_{jt}` follows an
independent AR(1) (stochvol). The free elements of `(A_1,...,A_p,c)` and of
U receive a hierarchical Normal-Gamma prior; the global shrinkage parameter
and the shape `a_tau` are sampled (random-walk Metropolis-Hastings). The
implementation supports four shrinkage schemes: `global`, `rowwise`,
`columnwise`, and `lagwise` (default; one global scale per lag).

## Files

```
NGVAR_replication/
  README.md
  ngvar_estim.R       core MCMC sampler + IRF helper
  simulate_data.R     synthetic stationary VAR(p) with SV (writes data_synth.rda)
  main_replication.R  driver: load data, run MCMC, compute IRFs and forecasts,
                      save output and figures
  data_synth.rda      generated by simulate_data.R
  output/             posterior draws and summaries (ngvar_results.rda)
  figures/            irf.pdf, predictive_density.pdf
```

## Dependencies

R packages: `MASS`, `mvtnorm`, `Matrix`, `stochvol`, `GIGrvg`, `coda`,
`ggplot2`, `reshape2`. All loaded via `require()` inside the estimator
(only `stochvol`, `GIGrvg`, `MASS`, `mvtnorm`, `Matrix` are strictly used
by the sampler; the others are optional for downstream plotting).

## How to run

From the replication folder:

```
Rscript main_replication.R
```

Override MCMC length on the command line:

```
Rscript main_replication.R nsave=500 nburn=250 seed=7
```

By default `main_replication.R` simulates data via `simulate_data.R`. To
use your own data, edit the clearly marked block in `main_replication.R`
("REPLACE WITH YOUR DATA"): supply a numeric `(T x M)` matrix `Y` and a
character vector `labels` of variable names.

## Output

- `output/ngvar_results.rda` contains: the full `fit` list (posterior
  draws of A, U, H, SIGMA at time T, SV parameters); the posterior median
  and 16/84% quantiles of the VAR coefficients; the IRF array and its
  pointwise quantiles; and the predictive draws `pred_store`.
- `figures/irf.pdf` shows orthogonal Cholesky impulse responses (rows =
  response variable, columns = shock) over a 20-period horizon with
  16/84% credible bands.
- `figures/predictive_density.pdf` shows a fan chart of the predictive
  density for the last variable over 8 horizons.

## Notes

- The estimator is self-contained: no path dependencies outside this
  folder, no cluster or parallel back-ends required.
- Cholesky identification: the ordering of variables in `Y` determines
  the structural interpretation of the shocks.
- For real-data work with M of moderate size (M up to ~20) the sampler is
  practical; runtime scales like O(M K^2) per equation per iteration.
